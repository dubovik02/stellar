# Stellar Burger

</div>

Реализация онлайн заказов в бургерной с использованием React, Redux и Typescript

Проект создан в учебных целях

---

## Технологии

Проект создан на базе:

-   React
-   React Router
-   Redux
-   Typescript
-   Vite
-   Jest
-   Cypress

## Реализованный функционал

-   Главная страница конструктора и ингредиентов.
-   Личный кабинет пользователя.
-   Лента заказов.

## Запуск проекта

Все команды выполняются из корня проекта.

Команды запускают SPA сборку на `5173` порту.

### Первичная настройка

1. Убедитесь что у вас установлен `node`.
2. Склонируйте репозиторий и перейдите в каталог проекта. 
3. Выполните команду `npm install`

### Режим разработки

`npm run dev` - запуск проекта для разработки в dev-режиме.

### Сборка production

`npm run build` - команда выполняет сборку проекта.

### Linters

`npm run lint` - проверка типов и стилей (eslint, stylelint).

### Unit-Тесты

`npm run test` - запуск тестов.

### E2E-Тесты

`npm run cypress:open` - запуск тестов.
